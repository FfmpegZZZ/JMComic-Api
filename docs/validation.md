账号测试覆盖身份隔离、每次资料读取重新登录、错误信息脱敏、加密状态与 Token 撤销、幂等写入收据、明确认证失败后重新登录、并发运行时上限、保存失败回退、迟到登录结果回收、配置快照回退。真实账号测试没有修改收藏、执行签到或强制制造上游会话过期。

离线图片固定为 512×768 JPEG；网络性能取决于 ARM 主机线路和实时上游。真实冷请求包含下载、解码、PDF 构建与发送，不等同于纯网络传输。cgroup 内存包含文件缓存和临时文件系统，不能与 RSS 直接混用。CPU/RSS 采样可能漏掉极短峰值。五轮仅提供该负载下的样本，不代表极限容量。

此前 JPEG optimize 本地对照、三页逐页内容流压缩的 Poppler 渲染对照已完成；尚未在 ARM 上分别切换编码策略重跑。单本 PDF 编码仍主要使用单核，冷路径是后续优化重点。

仍待验证或实施：Python 3.12/3.13 完整 Docker test target 执行、已有生产绑定目录的实际权限、活动下载/构建期间的容器 SIGTERM 回收验收、真实代理和认证过期联调。原生异步查询、跨线程 DNS/TLS 共享、跨作品公平图片调度与图片线程数档位对照尚未实施。多实例协调不在本轮范围。
